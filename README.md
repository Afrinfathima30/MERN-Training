# Job & Internship Tracker

A clean, modern and responsive frontend website designed to help students and job seekers discover opportunities, track applications and manage career deadlines in one place.

## Overview

The **Job & Internship Tracker** is a frontend web project created to simplify the process of managing job and internship applications.

Instead of keeping application details across multiple platforms, the idea is to provide a centralized and organized interface where users can discover opportunities and keep track of their career journey.

This project currently focuses on the **frontend UI**, built using pure HTML5 and CSS3.

---
